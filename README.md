# Scientific Visualization — Heart Failure Clinical Records

First assignment of the *Scientific Visualization* course (BSc Data Science & AI, UPM, 2025).

Exploratory analysis and unsupervised clustering on the
[Heart Failure Clinical Records Dataset](https://archive.ics.uci.edu/dataset/519/heart+failure+clinical+records)
(299 patients, 13 clinical features, binary `DEATH_EVENT` target).

## Contents

- `assign_1.ipynb` — Jupyter notebook with:
  - Exploratory data analysis and distribution plots (Matplotlib + Seaborn)
  - Feature standardization
  - **K-means** and **Agglomerative** clustering
  - Silhouette analysis for cluster validation
  - PCA projection for visualization

## Stack

`numpy` · `pandas` · `matplotlib` · `seaborn` · `scikit-learn` · `scipy` · `statsmodels`
